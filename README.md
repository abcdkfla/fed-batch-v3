# Fed-Batch Lab · 배양 워크스테이션

C. glutamicum 운전 조건을 비교하는 교육용 브라우저 시뮬레이터입니다. 실측 예측이나 실물 장비 제어용이 아닙니다.

## 실행 및 GitHub Pages

- 서버나 설치 없이 `index.html`을 브라우저에서 열면 실행됩니다. 단일 파일이며 외부 파일이 필요 없습니다.
- 저장소 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하세요.

## 앱으로 설치 (PWA)

- GitHub Pages 주소로 접속한 뒤 설치합니다.
  - Android Chrome: 메뉴 → 앱 설치
  - iPhone Safari: 공유 → 홈 화면에 추가
  - PC Chrome·Edge: 주소창 오른쪽 설치 아이콘
- 설치하면 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 실행됩니다. 저장소를 업데이트하면 다음 실행 때 반영됩니다.
- 상단의 **알림 켜기**를 누르면 재생 중 Fed-batch 진입, 산소 부족, 교반 속도 변경, 부피 상한, 24 h 완료를 알림으로 받습니다. 알림을 누르면 앱이 열립니다.
- iPhone 알림은 iOS 16.4 이상에서 홈 화면에 추가한 앱으로 실행했을 때만 작동합니다.

## 파일

- `index.html`: 시뮬레이터 전체 (단일 파일)
- `manifest.webmanifest`: 앱 이름·아이콘·표시 방식
- `sw.js`: 오프라인 캐시와 알림 처리
- `icons/`: 앱 아이콘

## 화면 구성

- **운전 모니터** · 한 줄 운전 설계(목록 + 직접 입력), 24시간 결과, 교반 변경 기록, 실시간 상태, 배양기 애니메이션, 7개 지표 통합 그래프. 구간과 그래프는 재생한 시점까지만 표시
- **조건 탐색 · 데이터** · 최고 수율 조건, 공급 개시 기준 1–5 g/L 비교, 30분 간격 기록, CSV 내려받기
- **실험 비교** · 24 h 완료 시 자동 기록(브라우저에 저장), 최대 4개 조건·결과 비교, 더보기로 2시간 간격 상세 데이터
- **수식 · 고정값** · 7단계 계산 흐름, 식 1–8과 변수 표, 현재 조건 대입값
- **논문 출처** · 인용 문헌, 모델 값과 원문 값 대조, 출처가 필요한 값

## 모델 범위

입력(목록 / 직접 입력): 목표 μ(0.1–0.4 / 0.01–0.44 h⁻¹), 초기 교반(100–1200 rpm, 100 / 1 단위), 초기 부피(0.5–2.5 L, 0.1 / 0.01 단위), 통기량(0.5 / 1 / 2, 0.1–3 vvm), 공급액 글루코스(100–800, 50–800 g/L), 공급 개시 기준(1–5, 0.1–10 g/L). 혼합 직후 배양기 내부 글루코스는 50 g/L 이하로 제한합니다.

초기 글루코스는 10 g/L. 잔류 글루코스가 기준 이하이면 공급하고, 초과하면 멈췄다가 다시 내려오면 재개합니다. 24시간까지 계산하며 2.5 L에 도달하면 공급을 멈춥니다.

수율 비교 지표는 순증가 균체량 / 소비 글루코스입니다. 산소는 단일 계수 12 mmol/g 근사이며, 공기 유량(L/min) = vvm × 현재 배양 부피(L)입니다. 목표 DO는 20%(1.51 mg/L)이며, 부피와 균체가 늘어 DO 20% 유지가 어려우면 교반을 100 rpm 단위로 1200 rpm까지 자동 증속합니다. 순산소는 포함하지 않습니다. DO는 정상상태 근사, 초기 OD600 0.20은 모델 가정이며, DCW 환산은 본 장비에서 검증되지 않았습니다.
