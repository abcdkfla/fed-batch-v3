# Fed-Batch Lab · 배양 워크스테이션

C. glutamicum 운전 조건을 비교하는 교육용 브라우저 시뮬레이터입니다. 실측 예측이나 실물 장비 제어용이 아닙니다.

## 실행 및 GitHub Pages

- 서버나 설치 없이 `index.html`을 브라우저에서 열면 실행됩니다. 단일 파일이며 외부 파일이 필요 없습니다.
- 저장소 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하세요.

## 화면 구성

- **운전 모니터** · 운전 설계, 배양기 애니메이션, 재생·이벤트 타임라인, 성장 / 산소·운전 그래프 6종
- **조건 탐색 · 데이터** · 공급 개시 기준 1–5 g/L 비교, 30분 간격 기록, CSV 내려받기
- **수식 · 고정값** · 7단계 계산 흐름, 식 1–8과 변수 표, 현재 조건 대입값
- **논문 출처** · 인용 문헌, 모델 값과 원문 값 대조, 출처가 필요한 값

## 모델 범위

입력: 목표 μ(0.1 / 0.2 / 0.3 / 0.4 h⁻¹), 교반(100–1200 rpm, 100 단위), 초기 부피(0.5–1.0 L, 0.1 단위), 통기량(0.5 / 1 / 2 vvm), 공급액 글루코스(100–800 g/L), 공급 개시 기준(1–5 g/L). 혼합 직후 배양기 내부 글루코스는 50 g/L 이하로 제한합니다.

초기 글루코스는 10 g/L. 잔류 글루코스가 기준 이하이면 공급하고, 초과하면 멈췄다가 다시 내려오면 재개합니다. 24시간까지 계산하며 2.5 L에 도달하면 공급을 멈춥니다.

수율 비교 지표는 순증가 균체량 / 소비 글루코스입니다. 산소는 단일 계수 12 mmol/g 근사이며, 공기 유량(L/min) = vvm × 현재 배양 부피(L)입니다. 순산소·자동 DO 제어는 포함하지 않습니다. DO는 정상상태 근사, 초기 OD600 0.20은 모델 가정이며, DCW 환산은 본 장비에서 검증되지 않았습니다.
